# pluginto40-lang.github.io

안드로이드 앱 "우리 아이 맞춤 영상"이 웹사이트
https://pluginto40-lang.github.io/vidioappforchild/ 의 주인임을 증명하는 파일을 두는 저장소예요.

- `.well-known/assetlinks.json` : 앱 서명 키 지문(공개해도 되는 정보)이 들어 있어요.
- `.nojekyll` : GitHub Pages가 `.well-known` 폴더를 숨기지 않게 해요.

앱 서명 키가 바뀌거나 Play 앱 서명 키 지문을 추가할 때 `assetlinks.json`만 고치면 돼요.
